Chave da API do YouTube

Fica salva só neste navegador. Sem ela o painel mostra dados de exemplo.

  1. Entre em console.cloud.google.com e crie um projeto.
  2. Em APIs e serviços → Biblioteca, ative a YouTube Data API v3.
  3. Em Credenciais → Criar credenciais → Chave de API.
  4. Restrinja a chave: sites https://pcxsar.github.io/* e só a YouTube Data API.

Puxar vídeos programados do YouTube

A chave da API só enxerga vídeos públicos. Para o painel ver os programados, você entra com a conta do canal (só leitura, ele não altera nada).

  1. Em APIs e serviços → Biblioteca, ative também a YouTube Analytics API (é ela que dá a % assistida e os números por dia).
  2. No mesmo projeto do Google Cloud, abra Google Auth Platform (ou "Tela de consentimento OAuth"), escolha Externo e, em Público-alvo → Usuários de teste, adicione o seu e-mail.
  3. Em Clientes (ou Credenciais) → Criar cliente → Aplicativo da Web. Em Origens JavaScript autorizadas, coloque https://pcxsar.github.io.
  4. Copie o ID do cliente (termina em .apps.googleusercontent.com) e cole aqui.
  5. Na aba Agenda, toque em Conectar em cada canal e escolha a conta daquele canal. Se aparecer "o Google não verificou este app", toque em Continuar.

Sincronizar a agenda pelo GitHub

Opcional. Salva a agenda e o histórico num arquivo de um repositório seu, para ver a mesma agenda no celular e no PC. Use um repositório privado para os dados.

  1. Crie um repositório privado, por exemplo painel-dados.
  2. Em GitHub → Settings → Developer settings → Fine-grained tokens, gere um token só para esse repositório, com Contents: Read and write.
  3. Preencha abaixo nos dois aparelhos.
